# TradePilot Android starter (prototype)

This project is an Android UI starter for a trading dashboard. It is **not a real trading app** yet and cannot place orders.


## Current features
- Android dashboard layout
- Demo balance display (₹100)
- Broker/data connection status placeholders
- Trading controls disabled
- Explicit warning that live trading is not connected

## What is still required for real-money use
1. Choose and open an eligible broker account.
2. Review the broker's API access, fees, authentication and current retail-algo requirements.
3. Build a secure backend for API authentication and order handling. Do not embed broker secrets in the Android app.
4. Implement real market data, strategy logic, order safeguards, audit logging and kill switch.
5. Verify compliance and test thoroughly before any live orders.

## Build
Open this folder in Android Studio and allow Gradle sync. Then select **Build > Build APK(s)**. The APK will be generated by Android Studio if the build succeeds.


## Important
The app's ₹100 is a display-only demo balance. No trades are simulated or executed.
